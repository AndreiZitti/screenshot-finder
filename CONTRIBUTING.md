# Contributing

Small, focused changes are welcome.

1. Create a branch from `main`.
2. Use Node.js 24 and install dependencies with `npm ci`.
3. Keep the interface mobile-first and preserve offline behavior.
4. Add or update tests for behavior changes.
5. Run `npm run check` before opening a pull request.

Do not commit `.env` files, API keys, access tokens, personal screenshots, or local assistant/tool configuration.
